# 记得住 · Keep in Mind

**长笔记直接变成复习计划，不用另做卡片。**

记得住是一个 Obsidian 插件。你照常用自己的话写学习笔记，每个值得记住的知识点用一个二级标题写成问题；学完点“完成学习”，之后它会在你快要忘记的时候安排复习：先只看问题回想，再展开正文核对，按想起的程度打分，下次复习的日期由打分自动决定。

适合已经在 Obsidian 里写课程、考试、语言等长篇学习笔记的人。

## 安装

需要 Obsidian 1.8.0 或更新的桌面版（macOS、Windows）。暂不支持手机和平板。

**方式一：用 BRAT 安装（推荐，之后能自动更新）**

1. 在 Obsidian 的“设置 → 第三方插件”里关闭安全模式，点“浏览”，搜索并安装 **BRAT**，然后启用它。
2. 打开命令面板（macOS `Cmd+P`，Windows `Ctrl+P`），运行 “BRAT: Add a beta plugin for testing”。
3. 填入仓库地址 `menjinqiu/keep-in-mind-releases`，确认。
4. 回到“第三方插件”，启用“Keep in Mind”。

**方式二：手动安装**

1. 在本仓库的 Releases 页面下载最新的 `keep-in-mind-V*.zip`。
2. 解压后得到 `keep-in-mind` 文件夹，把它放进你库里的 `.obsidian/plugins/` 文件夹（看不到 `.obsidian` 的话，在访达按 `Cmd+Shift+.` 显示隐藏文件；Windows 在资源管理器“查看”里勾选“隐藏的项目”）。
3. 重启 Obsidian，在“设置 → 第三方插件”里启用“Keep in Mind”。

手动安装的版本不会自动更新，有新版本时重复上面的步骤，覆盖旧文件即可，笔记和复习记录不受影响。

## 5 分钟上手

第一次启用时会出现新手引导，它会建好文件夹和两篇示例笔记。也可以按下面五步走：

1. 点左侧边栏的学士帽图标打开“学习空间”，点“新建学习”，输入这次学习的标题。
2. 边学边写。每个值得记住的知识点写成一个二级标题（`## `），标题写成一个问题，内容写在下面。
3. 学完打开操作面板，选“完成学习”。这篇笔记从明天起进入复习计划。
4. 之后每天打开学习空间，主页会告诉你今天有几篇要复习，点“开始复习”。
5. 复习时先只看问题，尽力回想，再展开正文核对，按想起的程度打 1–5 分。

插件里随时可以打开“使用说明”（命令面板运行“打开使用说明”），里面有完整说明和快捷键。

## 已经有很多笔记？

在左侧文件列表里右键一篇笔记或一个文件夹，选“加入复习”；或者打开笔记后在命令面板运行“把当前笔记加入复习”。确认后：

- 笔记会移到学习笔记文件夹，开头加一个知识块汇总，正文其余部分不改，原有属性保留；
- 它会算作“已完成”，明天开始复习；一次加入很多篇时，第一次复习会分散到之后几天，每天最多 10 篇；
- 有别的笔记链接到它时，Obsidian 会问是否更新链接（如果你开了“设置 → 文件与链接 → 自动更新内部链接”，就直接更新）。

## 数据与隐私

- 插件不联网，不收集、不上传任何数据。只读写你库里的文件和插件自己的设置文件。
- 学习笔记是普通 Markdown 文件；复习安排写在每篇笔记的属性里；复习记录在 `90 系统/复习日志.md`；插件设置在 `.obsidian/plugins/keep-in-mind/data.json`。
- 停用或卸载插件不会改动、也不会删除你的笔记和复习日志。卸载会删除插件文件夹（包括设置），重新安装后复习安排照常。

**备份**：备份整个库文件夹即可（同步盘、时间机器、Git 都可以）。

## 遇到问题

1. 在命令面板运行“复制使用摘要（反馈用）”，点“复制”。摘要只有数字（笔记篇数、复习次数、版本号等），不含任何笔记标题和内容，发送前可以先看一遍。
2. 把摘要连同问题描述（最好附截图）发到 **542957431@qq.com**。
